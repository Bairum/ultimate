# Graveyard of ideas

Ideas we built, tried and removed. Each gets a tombstone: what it was meant to do, what was built, why it went, and
how to bring it back from git. The code is deleted; the intent stays here so nobody rebuilds it without knowing how it
went last time.

Before building something that sounds familiar, check here first.

To bury an idea: screenshot it while it still runs, delete its code and every reference to it, and add a folder here
with a `README.md` tombstone and the screenshots, plus a line below.
