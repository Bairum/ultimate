## What each one is

|                                 | Kind                                                 | One line                                                                                                                                                                                                                                                                                                                                           |
| ------------------------------- | ---------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **cua**                         | Platform: driver, sandboxes, VMs, models, benchmarks | Cua Driver (Rust, MCP over stdio) drives native apps in the background on macOS, Windows and Linux. The `cua` SDK/CLI makes sandboxes (gVisor containers, QEMU, Lume macOS VMs, cloud). Lume runs macOS/Linux VMs on Apple Silicon. Cua Spaces is a desktop app. CUA-S1 are small decision models. The older Python agent SDK has 20+ model loops. |
| **omp**                         | Built-in harness feature                             | A native Rust addon plus a Bun worker, exposed as the `computer` global inside omp's Eval (JS/Python) tool. Off by default, `/computer` toggles it.                                                                                                                                                                                                |
| **jev-codex-cua**               | Pi package                                           | Pi tools over **OpenAI Codex's bundled "Sky" computer-use runtime** (`SkyComputerUseClient.app` in the Codex app). It has a native mode, and a Jev mode where TypeSafe Jev picks the next AX element as text. macOS only, experimental.                                                                                                            |
| **@amaster.ai/pi-computer-use** | Pi package                                           | Pi wrapper around **Cua Driver 0.37.0** (`cua-driver mcp`). It proxies 62 driver tools with a `computer_use_` prefix, a "core" profile and confirmation prompts.                                                                                                                                                                                   |
| **Anthropic computer use**      | Model API tool                                       | `computer_toolset_20260801` (Claude 5.5+, no beta header) with 17 member tools, or `computer_20251124` (beta, Opus 4.5 to 5.x). Pixel-based, client-executed.                                                                                                                                                                                      |
| **OpenAI computer use**         | Model API tool                                       | Responses API `{type: "computer"}` (for example `gpt-6.1-sol`), or a code-execution variant where the model writes PyAutoGUI/Playwright code. Driven through the SDK `ComputerToolset` with an app-supplied driver.                                                                                                                                |

## Quality notes

- **cua Driver** is the most mature backend. It has a typed contract (`contract/manifest.json`, MCP `2025-06-18`), per-OS end-to-end harnesses, an empirical action ledger, background delivery that keeps the user's pointer and focus, and structured refusals. It moves fast: 0.28→0.38 made breaking schema changes (`element_index` → `element_token`, `set_config`), so Ultimate must pin a version.
- **omp** is the deepest single-machine implementation: frame-bound coordinates, stale-ref recovery, user-intervention detection, a release guard for held keys, display-sleep assertions, an Escape stop counter. It is also the most coupled: Bun worker, Eval prelude, omp's approval and session classes, 53k lines of Rust behind NAPI. Its TCC grants attach to whatever process hosts it.
- **jev-codex-cua** has good discipline (single-use 60 s state tokens, no automatic replay of unknown outcomes, tests with simulated drivers), but it rests on a closed runtime, runs on macOS only, and calls itself experimental.
- **amaster** is a thin, careful wrapper (bounded results, deferred tool groups, reconnects). Most of its 15k lines are a generated tool manifest.
