This folder is Ultimate's project configuration when the clone itself is the project. Commit project-specific extensions, agents, skills, surfaces, and optional `settings.json` here; the documented setting `defaultSurface` names the preferred surface. Built-ins remain in the clone's top-level folders, user overrides live in `~/.ultimate/`, and runtime state is stored separately under `~/.ultimate/projects/` (or `ULTIMATE_HOME`).
