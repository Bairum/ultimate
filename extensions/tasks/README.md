The live durable task graph in the right panel's Tasks tab: every conversation with live work, its tasks as a tree by owner (generation → tool calls → the conversations a task owns, such as subagents), each with its status (pending, the running phase, waiting on which tasks, completing), and background and aborting marks. There is no timer: Pi Durable's task graph carries no times, and a count from when the page first saw a task would look like how long it ran. Click a conversation to show it.

Data comes from `useTasks()` (the server's `tasks` event) and `useConversations()`; tool names of the shown conversation's tool tasks come from `pi.live`.
