The live durable task graph in the right panel's Tasks tab: every conversation with live work, its tasks as a tree by owner (generation → tool calls → the conversations a task owns, such as subagents), each with its status (pending, the running phase, waiting on which tasks, completing), background and aborting marks, and how long it has run, from the task record's durable `startedAt` (warning colour after ten minutes, so a stuck task stands out). Top-level conversations show their feature tag; a conversation linked to a plan task shows the plan's `TaskChip` before its title. Click a conversation to show it.

Data comes from `useTasks()` (the server's `tasks` event), `useConversations()` and the conversations overview document; start times come from the `started {ids}` action, asked once per task since they never change; tool names of the shown conversation's tool tasks come from `pi.live`.
