What this Ultimate runs on, in the right panel's Info tab: machine, process (uptime, generation, restart), persistence, execution environment, code (branch, sha, dirty, build, "core changed · restart pending"), the shown conversation's model and usage, every extension with its facets, tools, prompt sections, documents and load errors, skills, context files, and subagent definitions.

Everything comes from `useSystem()` (the server's `system` event), `useConversation()`, `useModels()`, and `useExtensions()` for web-facet load errors. Paths copy on click; which sections are collapsed is kept in durable UI state. `rows.tsx` holds the section, row, and copy primitives.
