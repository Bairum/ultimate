Model, thinking, and login, as Pi does them: a model button and a thinking-level button in the composer toolbar, a searchable model picker grouped by provider (availability, login status, context window, thinking, price per million tokens), and a login dialog that drives any pi-ai provider's flow, subscription or API key, with credentials shared with pi in `~/.pi/agent/auth.json`.

Picking a model calls `api.configure({ model, thinkingLevel })` with the thinking level clamped to what the model supports; a model whose provider is not logged in opens the login for that provider. Shift+Tab cycles the thinking level like Pi. The login dialog renders the server's `auth` events (`auth_url` with open and copy, `device_code` with a countdown, `info`, `progress`) and answers `text`, `secret`, `select`, and `manual_code` prompts with `api.answer`; closing it cancels a running flow, and configured providers can log out. Commands: `model.pick`, `model.thinking`, `model.thinking.cycle` (Shift+Tab), `auth.login`; the status line's model opens the picker through `model.pick`.

`picker.tsx` is the model picker, `login.tsx` the login dialog, `state.tsx` the shared helpers (clamping, dialog ids, which provider the login opens on).
