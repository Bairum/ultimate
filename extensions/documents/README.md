Show the shown conversation's extension documents in the right panel, each through its extension's renderer or as JSON.

`web.tsx` adds the Documents tab. It reads which kinds exist from the system info (each server facet's `docs` export, `server.docs` in the Info panel) and streams each with `useDocKind`, which creates a missing document with its initial value. Kinds that a web facet registers a renderer for (`documents: [{ kind, title, icon?, component }]`, resolved with `useDocumentRenderers`) come first and open, under the renderer's title; the rest show as a JSON tree under their kind, folded. Folding is durable per kind (`ext.documents.open`). Each renderer runs inside an `ExtensionBoundary` naming its extension: a renderer that throws shows an error card with the JSON tree below it, and the other documents keep working. Nothing here edits a document.
