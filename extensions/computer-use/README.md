Computer use operates native apps on this Mac through Cua Driver, with TypeSafe Jev driving routine steps; it is in development and off by default.

The design lives in [docs/design/computer-use/](../../docs/design/computer-use/README.md). This folder ships empty until
phase 1 lands, so that the extension is registered off by default (`defaultOff` in `shared/extension-api.ts`) before
any tool exists.
