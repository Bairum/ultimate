What the model saw before a conversation's first input: a quiet header above it names the agent, its model and the estimated token budget, and opens to the agent's definition, the system prompt section by section, the tools with their schemas, and the context injected before the input (a branch's memory brief or tally, a compaction summary, a fork's inherited history), each with its tokens and share.

A later context start (a compaction, a reset) shows its own breakdown under its card. A `pi.system` patch mid-conversation stays a one-line marker, `Reloaded` for a hot reload, `Restarted` for a same-build restart, `system prompt` otherwise, that opens to a diff: each section and tool added, changed or removed, with its token delta and full text. A remove-all patch Pi Durable writes before a reordered re-add folds into that re-add's diff.

A branch is a fork of its root; the transcript hides the inherited root history before its own first entry and stops paging there, since the brief the header shows is what the branch actually starts from.

`breakdown.ts` is the pure model (replaying `pi.system` patches from the last context start, estimating tokens with Pi's `estimateTextTokens`: 3.5 characters per token, an image a fixed 4800 characters). `web.tsx` renders the header through the core `transcript.start` slot, which the transcript shows above its first row once its whole history is loaded, and renders `pi.system`, `pi.reset` and `pi.compaction` entries. It shows only what entries record as sent to the model; settings, provider headers and secrets are never read.
