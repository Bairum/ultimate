# Ultimate

A local coding agent with a web UI that builds itself while it runs. Built on
[Pi Durable](https://earendil.com/posts/pi-durable/): conversations, tool calls, and subagents survive restarts and
crashes, so the agent can rewrite its own UI, extensions, and core without losing its place.

See [AGENTS.md](AGENTS.md) for how it is put together.
